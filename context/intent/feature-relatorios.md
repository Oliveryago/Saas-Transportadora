# Feature: Relatórios e Exportação

## What

Módulo dedicado à geração de relatórios tabulares consolidados e exportação de dados. Permite que gestores extraiam dados do sistema para análise externa ou prestação de contas.

## Why

Apesar dos dashboards fornecerem visão macro, gestores frequentemente precisam manipular dados no Excel ou enviar relatórios em PDF para clientes, contabilidade ou auditoria. A capacidade de exportar dados é um requisito padrão para softwares de gestão empresarial.

## Acceptance Criteria

- [x] Relatórios consolidados combinando diferentes fontes de dados
- [x] Geração de relatórios em formato PDF com layout formatado (tabelas, logos)
- [x] Geração de relatórios em formato Excel (.xlsx) para manipulação de dados
- [x] Filtros por veículo, período e tipo de dado
- [x] Acesso restrito a administradores e gestores
